# Changelog

## 2.0.0

- Rebuilt the desktop app with an Electron, JavaScript, HTML, and CSS interface.
- Added library, launcher and platform collection filters, Steam achievements, and Big Picture mode.
- Added emulator setup, local cover recovery, custom gaming themes, and an OBS browser source.
- Keeps player data in the local Windows profile rather than in the application package.
- Released under the MIT open-source license; commercial use and redistribution are allowed when the copyright and license notice are retained.
